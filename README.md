# 上毛かるた

webxdc対応メッセンジャーの同じチャットで、読み手が出題し、参加者が自分の端末で札を取るアプリです。44札を収録し、個人戦・団体戦、男性・女性の内蔵音声、参加者端末での読み上げに対応しています。

- バージョン：**1.0.4**
- README更新日：2026年10月18日
- 個人戦の基本構成：読み手1人と参加者2人、合計3台

| ファイル | 用途 |

## 通信対戦を始める

1. 全員が参加しているwebxdc対応メッセンジャーのチャットに、`jomo-karuta-1.0.4.xdc` を1回投稿します。
2. **全員がその同じアプリ投稿を開きます。** 別々に投稿したアプリや以前の版の投稿では、対戦が分かれます。
3. 「通信準備完了」を確認します。
4. 参加者が「赤で参加」または「白で参加」を押します。
5. 読み手が「この端末を読み手にする」を押します。読み手は札を取れません。
6. 読み手がモードと枚数を選び、「試聴」で音を確かめます。
7. 全員の参加を確認して「ゲーム開始」を押します。
8. 読み手が「次を読む」を押し、参加者は該当する札を押します。

最初は10枚の個人戦を手動で進めてください。個人戦には読み手以外にちょうど2人、団体戦には赤白それぞれ1人以上が必要です。枚数は10・20・30・44枚から選べます。

## 読み手の操作

| ボタンや設定 | 動作 |
| --- | --- |
| 次を読む | 次の札を出題して読み上げる |
| もう一度 | 現在の札を再読し、読み上げONの参加者端末にも再読を指示する |
| 自動OFF／自動ON | 自動進行の切り替え。間隔も選択できる |
| 1回読み／2回読み | 読み手端末での読み回数を選ぶ |
| 音声を停止 | 現在の音声を止める。自動進行を止める場合は別途、自動をOFFにする |
| 終了 | 最後の札の後に表示される。回答の反映を待ってから押す |

読み手の端末は対戦終了までアプリを開いたままにしてください。次の問題へ進んだ後に届いた前の問題の回答は採点されません。

## 音声を設定する

声や再生方法は、**各自の端末で選びます。** 読み手の音声設定は参加者端末へ引き継がれません。

| 再生方法 | 内容 |
| --- | --- |
| 自動 | Androidでは内蔵音声を使用。iPhone・PCでは端末の音声合成を使用し、起動エラーや無応答の場合は内蔵音声へ切り替える |
| 内蔵音声 | 男性・女性それぞれ44札、計88音声を収録。外部ネットワークや端末の音声合成に依存せず再生する |
| 端末の音声合成 | 端末にある声を使用。利用できる声や機能は環境により異なる |

「男性」「女性」を押して試聴してください。内蔵音声の初期設定は女性です。内蔵音声では速度を変更できますが、高さの変更は反映されません。端末音声での男女の選択は、利用できる声に左右されます。

内蔵音声の再生自体に通信は不要ですが、端末間の出題・回答・得点の共有にはメッセンジャーの通信が必要です。

## 参加者の端末でも読み上げる

参加者の読み上げは、起動時はOFFです。

1. 各参加者が「この端末でも読み上げる」を押します。
2. 試聴を確認し、必要に応じて「男性」「女性」や再生方法を選びます。
3. 次に届く出題から、その端末で読み上げます。
4. すでに表示されている札を聞く場合は「今の札を聞く」を押します。
5. 音を出さない場合は「この端末の読み上げをOFFにする」を押します。

アプリを閉じて開き直したときは、もう一度ONにしてください。履歴を復元しても、過去の札を順番に読み直すことはありません。同じ部屋で音が重なる場合は、必要な端末だけをONにします。

参加者側は読み手の音声を中継しているのではなく、届いた出題に合わせて端末内で再生しています。通信状況により、再生開始には時間差があります。

### 読み上げOFF時のテキスト表示

読み上げON／OFFで、出題の表示内容は変わりません。

- 出題欄には、先頭のかな・札の名前・場所が表示されます。
- 例：「つ」「群馬県の形」「群馬県」。
- 出題欄に、読み札のひらがな全文・漢字全文は表示されません。
- 取り札には短い名称と読みも表示されますが、表示幅に応じて省略されます。
- 音声OFFでも札を取る操作はできます。

## 得点と勝敗

このアプリ独自の簡易ルールです。

| 状態 | 採点 |
| --- | --- |
| 正しい札を押す | 読み手が最初に受け付けた人に1点 |
| 違う札を押す | 1点減点。同じ人は同じ問題につき1回まで |
| 正解が確定した後の追加回答 | その問題では採点しない |
| 個人戦 | 得点が多い人の勝ち。同点は引き分け |
| 団体戦 | チーム合計が多い側の勝ち。同点は引き分け |

「回答を送信しました」は獲得の確定ではありません。得点と、札に表示される獲得者を確認してください。判定は読み手端末の受付順なので、実際に押した瞬間の順番とは異なる場合があります。厳密な早押しの公平性や、正式競技の採点方式を保証するものではありません。

終了後は、必要に応じて参加チームや読み手を選び直し、再び「ゲーム開始」を押します。新しい対戦は0点から始まります。対戦中に参加者を変更したい場合は、次の対戦まで待ってください。

## ブラウザーだけで使う

`index-1.0.4.html` または `index.html` をブラウザーで開きます。「この端末を読み手にする」から、参加者なしでゲームを開始し、読み上げ用に使えます。

ブラウザー単体では端末間通信はできません。ページを閉じると対戦はリセットされます。HTMLには音声を埋め込んでいるため、単独のファイルで使えます。

## 困ったとき

| 困ったこと | 確認と対処 |
| --- | --- |
| Androidで音が出ない | 「内蔵音声」を選び、「試聴」を直接押す。メディア音量とBluetooth・イヤホンなどの出力先を確認する |
| 男性の声にならない | 1.0.4の投稿か確認し、その端末で「内蔵音声」と「男性」を選ぶ |
| 参加者端末で音が出ない | 「この端末でも読み上げる」を押す。現在の札は「今の札を聞く」で確認する |
| 自動再生が止められる | 「試聴」「もう一度」「今の札を聞く」を直接押して再生する |
| 音声が重なる | 同じ部屋では参加者の読み上げをOFFにする |
| 参加者や得点がそろわない | 同じチャットの同じ投稿か確認し、通信を待つ。続く場合は同じ投稿から開き直す |
| 読み手を閉じてしまった | 同じ投稿から開き直す。まだ現在の問題で反映しない回答は、参加者が再送する |
| ゲーム開始できない | 通信準備、読み手の設定、モードに必要な参加人数を確認する |

## 更新と確認範囲

1.0.4では、Android向けの男性音声と、参加者端末での読み上げON／OFF、読み手からの再読指示を追加しています。更新するときは、新しい `.xdc` をチャットへ投稿し、全員がその同じ投稿を開いてください。

以下を模擬環境とブラウザーで確認しています。

- 3端末を模した参加・出題・回答・採点・終了・再対戦。
- 重複配送、古い対戦の回答、履歴復元による状態の整合性。
- 男性・女性88ファイルのデコード、長さ、無音でないこと。
- 音声合成APIのないAndroid相当の環境での内蔵音声再生。
- 参加者の出題・再読時の再生、OFF、履歴を読み上げないこと。
- PCの端末音声経路と、エラー時の内蔵音声への切り替え。

実際のメッセンジャーとAndroid・iPhoneの複数実機による通信・音声出力は未確認です。初回は10枚で一通り試してから利用してください。PDFマニュアルは全ページの表示を確認済みです。Word版は描画環境がないため、最終表示は未確認です。
